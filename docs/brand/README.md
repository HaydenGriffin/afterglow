# Afterglow brand

**Last light**: a dark screen with one sliver of light breaking out past its edges. The TV goes off, the glow lingers.

| File | Use |
|---|---|
| `afterglow-horizontal.svg` | Primary logo on light backgrounds |
| `afterglow-horizontal-reversed.svg` | Primary logo on dark backgrounds |
| `afterglow-horizontal-ink.svg` | One colour (ink), e.g. print, stamps |
| `afterglow-stacked.svg`, `-reversed.svg` | Square formats |
| `afterglow-symbol.svg`, `-reversed.svg`, `-ink.svg` | Symbol from 40 px up |
| `afterglow-symbol-small.svg`, `-small-ink.svg` | Symbol at 32 px and below (thicker, shorter sliver) |
| `afterglow-wordmark.svg`, `-reversed.svg` | Wordmark only |
| `afterglow-app-icon.svg` | Launcher icon master: ink mark on an ember tile, full bleed |
| `afterglow-favicon.svg` | Browser tab icon (same tile, larger mark) |
| `social-preview.png` (`.svg`) | GitHub social preview, 1280×640 |

## Colours

| Name | HEX | RGB | Role |
|---|---|---|---|
| Ember | `#EE7A3B` | 238 122 59 | The sliver of light and the app-icon tile; nowhere else |
| Ink | `#121417` | 18 20 23 | The screen and the wordmark |
| Paper | `#EFEBE3` | 239 235 227 | Reversed logo |

Ember belongs to the logo only. The app UI keeps the No Brand Accent Rule in [DESIGN.md](../../DESIGN.md).

## Rules

- Clear space on every side: the sliver's overhang past the square (about a fifth of the square's side).
- The full-colour logo goes on light backgrounds. On dark ones use `-reversed`; on launchers and tabs, the ember tile.
- Under 40 px use the small cut or the app icon; under 120 px wide use the symbol, not the horizontal logo.
- Don't stretch, rotate, recolour, retype the wordmark (Archivo 800, outlined, custom spacing), or add effects.

## App icons

`app/icon.png` (80×80) and `app/largeIcon.png` (130×130) are `afterglow-app-icon.svg` rendered at those sizes;
`app/favicon.svg` and `app/favicon.ico` are the favicon for the browser demo. To re-render after changing a master,
open the SVG in Chrome and screenshot it at the exact size, or use any SVG renderer
(`rsvg-convert -w 130 -h 130 afterglow-app-icon.svg -o ../../app/largeIcon.png`).

The masters are generated by the brand kit (kept outside this repo); edit them there, not by hand.
